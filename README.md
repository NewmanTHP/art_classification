# WikiArt-ViT: Global Context Attention for Artistic Style Classification

Classifying artistic movements with Vision Transformers instead of CNNs — because style lives in the
relationship between brushstrokes across the whole canvas, not just in local edges.

## 1. Problem Statement

Automated art classification is a distinctive computer vision problem because artistic movements are rarely
defined by localized object boundaries alone. Traditional convolutional neural networks (CNNs) lean heavily on
local spatial features — edges, textures, distinct shapes — which fall short when distinguishing stylistically
adjacent movements such as Impressionism and Expressionism. Style is instead a *global* property: overall
color distribution, lighting composition, and the continuity of brushwork across the entire canvas.

This project explores **Vision Transformers (ViTs)** as an alternative to CNN backbones for this task. Because
self-attention relates every image patch to every other patch from the first layer onward, a ViT has a global
receptive field from the start — a property that should matter for a task defined by whole-canvas structure
rather than local objects.

## 2. Dataset & Preprocessing

The project uses the public **[WikiArt](https://huggingface.co/datasets/huggan/wikiart)** dataset — roughly
80,000+ digitised paintings labelled across 20+ artistic styles/movements (mirrored on the Hugging Face Hub as
`huggan/wikiart`, sourced from [wikiart.org](https://www.wikiart.org/)).

Pipeline (see [`src/data.py`](src/data.py)):

1. **Load** the dataset via `datasets.load_dataset`.
2. **Filter rare classes** — styles below a configurable minimum sample count (default: 300) are dropped to
   preserve balanced representational depth per class.
3. **Stratified split** into train / validation / test (default `70/15/15`), stratified on style label.
4. **Resize & normalise** to `224×224` using the ImageNet mean/std expected by
   `google/vit-base-patch16-224-in21k`.
5. **Light augmentation** (train split only): `RandomResizedCrop` (mild scale range), subtle `ColorJitter`,
   and `RandomHorizontalFlip`. Augmentation is deliberately conservative — heavy distortion (large rotations,
   strong color/contrast shifts, cutout) is avoided because it can destroy the very stylistic cues (palette,
   brush continuity) the model is meant to learn.

## 3. Model Architecture & Methodology

Core classifier (see [`src/model.py`](src/model.py)):

- Backbone: pre-trained **`google/vit-base-patch16-224-in21k`** (Hugging Face `transformers`).
- Each `224×224` image is split into non-overlapping `16×16` patches (`14×14 = 196` patches), linearly
  projected into patch embeddings, prepended with a `[CLS]` token, and passed through a multi-head
  self-attention transformer encoder.
- A custom linear classification head replaces the pre-training head, sized to the number of retained
  WikiArt style classes.

**Two-phase transfer learning** (see [`src/train.py`](src/train.py)):

| Phase | Backbone | Trained | LR schedule |
|---|---|---|---|
| 1 — Head warm-up | Frozen | Classification head only | Constant / linear warm-up |
| 2 — Fine-tuning | Unfrozen | Entire network | Cosine annealing, low peak LR |

A ResNet-50 (ImageNet pre-trained) is trained under the same pipeline as a **baseline** for comparison
(`src/model.py::build_resnet_baseline`).

## 4. Evaluation & Interpretability

- **Metrics** (`src/evaluate.py`): top-1 and top-5 accuracy, macro-averaged F1, and per-class
  precision/recall/support, plus a confusion matrix.
- **Interpretability** (`src/interpretability.py`): **attention rollout** across the transformer's
  self-attention layers, producing a heatmap over the original canvas showing which regions — broad
  background brushwork vs. focal subject matter — the model weighted most heavily for its prediction.
- **Benchmarking**: ViT results are reported side-by-side with the ResNet-50 baseline on identical splits.

## 5. Deliverables

- Reproducible PyTorch / Hugging Face `transformers` codebase (this repo).
- Benchmark report: ViT vs. ResNet-50 baseline (`reports/`, generated by `src/evaluate.py`).
- Attention rollout visualisations for qualitative interpretability (`reports/attention_maps/`).
- An interactive **Gradio** web app (`app.py`) for real-time style prediction on uploaded artwork, with
  attention overlay.

## Quickstart

```bash
# 1. Environment
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 2. (Optional) Pre-cache the dataset locally
bash scripts/download_data.sh

# 3. Train — phase 1 (frozen backbone) then phase 2 (fine-tune) run automatically
python -m src.train --config configs/config.yaml

# 4. Evaluate against the ResNet-50 baseline
python -m src.evaluate --config configs/config.yaml --checkpoint checkpoints/vit_best.pt --baseline

# 5. Launch the interactive demo
python app.py
```

Adjust dataset filtering thresholds, batch size, learning rates, and epoch counts in
[`configs/config.yaml`](configs/config.yaml) rather than editing source files directly.

## Hardware Notes

`vit-base-patch16-224` fine-tuning is comfortable on a single 16GB+ GPU with a batch size of 32–64 at
`224×224`. CPU-only training is possible for the frozen-backbone phase (small classification head) but not
recommended for full fine-tuning. Mixed precision (`--fp16`) is supported via `torch.cuda.amp` and is on by
default when a CUDA device is available.
